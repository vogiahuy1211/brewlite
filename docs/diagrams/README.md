# Thư mục này chứa tất cả sơ đồ UML của hệ thống BrewLite (Task 2).

## Quy ước lưu file

Mỗi sơ đồ được lưu theo cặp:
- **Mã nguồn:** `.puml` (PlantUML) hoặc `.mmd` (Mermaid) — dùng để chỉnh sửa
- **Ảnh render:** `.svg` — dùng để nhúng vào báo cáo và tài liệu

## Danh sách sơ đồ

| File | Loại | Mô tả |
|---|---|---|
| `activity-checkout.puml/.svg` | Activity Diagram | Luồng End-to-End từ xem menu đến xác nhận đơn |
| `sequence-checkout.puml/.svg` | Sequence Diagram | Tuần tự giao tiếp cho use-case Đặt & Thanh toán |
| `class-domain.puml/.svg` | Class Diagram | Mô hình lớp nghiệp vụ (Domain Model) |
